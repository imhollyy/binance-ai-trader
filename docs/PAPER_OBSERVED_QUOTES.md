# BT-007A — Observed public Spot PAPER reference pricing

**PAPER ONLY.** This module never places an exchange order, fetches authenticated account details, schedules a worker, or asserts that an actual Binance trade filled at the reference price.

## Source and observation semantics

The official Binance public market-data-only host `https://data-api.binance.vision` supports `GET /api/v3/klines` and `GET /api/v3/ticker/price` without authentication. See [official API-only list](https://github.com/binance/binance-spot-api-docs/blob/master/faqs/market_data_only.md). The **symbol price ticker does not return a Binance event/trade timestamp**. Therefore `requested_at_ms` and `received_at_ms` are the local machine's UTC milliseconds *measured around the REST request*, **not exchange timestamps**, and `exchange_price_event_time_ms` is explicitly `None`. Quote receipt time is not matching-engine time, a guaranteed executable offer, or an execution receipt. No best-bid/ask, depth, fills or latency guarantees are modeled.

`PublicSpotObservationClient.observe(...)` issues exactly one public closed kline request and one ticker last-price request. There are **no retries or loops**: 418/429 with Retry-After, non-200, network errors, malformed JSON, unsupported symbol, or invalid decimal FAIL CLOSED. No caller `SourceState.HEALTHY` flag can substitute for both public replies. The injected `MockTransport` and fake clock are for isolated offline tests only.

50–1000 historical closed, continuous and strictly ordered Spot candles are required. Ticker starts after the latest closed candle; the complete receive-time window must be <= 3000ms, with the whole sample still inside the *next* interval. A second pre-settlement quality pass checks quote age <= 3000ms, UTC order, unchanged latest closed candle, symbol, interval, positive finite Decimal price, and conservatively a <= 5% difference from the last candle close. No prediction or market fill is inferred from this deviation check; genuine fast market moves may be rejected for safety.

## Transactionally joined quote evidence

`run_observed_paper_spot_once(engine, observer, symbol=..., interval=..., params=...)` is explicitly a **single synchronous call**, not a scheduled service. It fetches the trusted source observation internally, then checks a READ ONLY PostgreSQL snapshot of persisted settings/account/positions/journal and that the entire public historical candle prefix matches the stored prefix. The only built-in trusted SMA strategy evaluates this latest fully closed prefix. If no cross exists, it returns `NO_SIGNAL` with **no database write**.

If a cross exists, a stable signal key shared with BT-006B and an existing PostgreSQL UNIQUE journal/position idempotency path are used. The existing `paper_execution` account-locked transaction **revalidates** settings version, approval policy, position state, stored/public candle equality, current quote age and the SMA decision before any write. The same observed ticker last price—not a later available candle's OPEN—is passed to the immutable PAPER fill calculator with explicit adverse slippage and taker fee. The existing stop, capital, daily realized loss, journal reconciliation and decimal precision remain enforced; a gap below the stop is rejected rather than silently fixed. An identical concurrent request cannot double-debit the PAPER account. Two distinct prices for the same signal key conflict rather than producing two different fills.

Migration `0004_paper_spot_observed_quotes` ADDS `paper_spot_observed_quotes` without modifying any existing ledger row. Each newly written PAPER journal entry from this path gets an **atomic, one-to-one, append-only** quote observation audit row with symbol/interval, strategy candle close time, local request/receipt times, public source label, observed raw reference price, and fee/slippage bps. If audit insertion fails, the whole PAPER trade rolls back. UPDATE, DELETE and TRUNCATE on audit rows are blocked by PostgreSQL triggers. Downgrade refuses to discard a non-empty audit.

**Boundary:** A local client clock can be wrong and the Binance ticker can be cached/delayed upstream. This module cannot prove exchange timestamp, true spread, liquidity or fill, nor does a 5% guard authenticate the price against another market. This version has no public endpoint and no background scheduler; production-like 7/24 PAPER operation, backoff/monitoring, signed user authentication, UI, backups and Cloudflare access remain later independent tasks. Legacy BT-006B historical next-candle-open replay remains labeled as **retrospective** and is not silently converted to a live quote.
